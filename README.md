Краткое руководство по основным командам Git для работы с проектом.

## 🚀 Быстрый старт
1. Склонировать удалённый репозиторий в папку: `git clone git@github.com:techchronicler/git-guide.git`
2. Получить изменения из удалённого репозитория: `git pull`  
3. Проверить статус репозитория: `git status` 
4. Внести необходимые изменения в файлы проекта (терминал можно закрыть).
5. Открыть терминал в папке проекта. Добавить все изменённые файлы/папки в индекс: `git add .`  
6. Внести изменения однострочным сообщением — кратко описать, что сделано: `git commit -m "актуализировано в соот. с версией Х"`  
7. Отправить изменения в удалённый репозиторий: `git push`

Изменения появятся в GitHub. Действия 2–7 производить каждый раз. Остальное — единоразово для создания папки с репозиторием на своём ПК.

## 🛠 Работа с ветками и другие команды
- Изменение последнего коммита: `git commit --amend -m "Твой изменённый комментарий"`
- Откат последнего коммита: `git revert HEAD`
-  Создание отдельной ветки для параллельной работы над проектом:

```bash
git branch setezor_online          # создать ветку
git switch setezor_online          # переключиться на ветку
git switch main                    # вернуться на main
git status                         # проверить, к какой ветке подключён
git add .                          # добавить изменённые файлы
git commit -m "<текст>"            # добавить коммит
git push -u origin <имя-ветки>     # запушить изменения в определённую ветку
```
