Когда [SSH-ключ для работы с GitHub](1.%20Подготовка%20SSH-ключа%20для%20работы%20с%20GitHub.md) настроен, можно перейти к созданию репозитория, в котором будут находиться работы.

1. Перейти в свой профиль GitHub и нажать на иконку профиля в правом верхнем углу. В выпадающем меню выбрать «Repositories».

![](../screenshots/20260909151659.png)

2. На странице `https://github.com/<name>?tab=repositories` нажать на кнопку «New».

![](../screenshots/20260909145424.png)

3. Появится страница создания нового репозитория. Нужно заполнить следующие поля:
- «Repository name» — название репозитория;
- «Description» — описание репозитория;
- «Choose visibility» — видимость репозитория. В выпадающем меню выбрать Public или Private. Public (публичный) — любой пользователь сможет зайти, прочитать и использовать файлы в своих целях. Private (приватный) — репозиторий виден только создателю и тем, с кем он поделился доступом;
- «Add README» — это файл с основной информацией о проекте, который автоматически открывается при заходе на страницу репозитория. В README обычно пишут: краткое описание проекта, оглавление или список разделов гайда, инструкции по установке или началу работы, ссылки на дополнительные ресурсы. Нужно переключить тумблер в положение «On»;
- «Add .gitignore» — файл, который говорит Git, какие файлы и папки не нужно отслеживать (например, временные файлы, кэш, логи). Для репозитория с текстовыми инструкциями (без кода на конкретных языках) можно оставить «No .gitignore»;
- «Add license» (Лицензия) — лицензия объясняет, как другие могут использовать контент автора. Для обучающего материала можно рассмотреть «MIT License» и «Creative Commons Attribution (CC BY)». В первом случае лицензия разрешает использовать, изменять и распространять материал при условии указания автора. Во втором случае хорошо подходит для документации и гайдов: разрешает любые действия при указании авторства. Можно пока оставить «No license» и позже отредактировать.

![](../screenshots/20260909151812.png)
4. Когда все поля заполнены, нужно нажать «Create repository».

![](../screenshots/20260909153437.png)

5. Как итог будет готовый репозиторий. При желании его можно отредактировать, нажав на «Settings» в панели сверху.

![](../screenshots/20260909153555.png)

Далее можно перейти к [клонированию репозитория](3.%20Работа%20с%20Git.md) и загрузке в него файлов.
