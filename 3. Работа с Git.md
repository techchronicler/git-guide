Если SSH-ключ настроен и выбран интересующий репозиторий, можно приступить к основной работе.

1. В репозитории нажать «<> Code» и в выпадающем меню выбрать «SSH», скопировать предлагаемую ссылку.

![](../screenshots/20260909172221.png)


2. Открыть терминал сочетанием клавиш Ctrl + Alt + T и выбрать папку, в которую нужно клонировать репозиторий, или создать папку, например:
- `cd Документы` — перейти в папку «Документы»;
- `mkdir <название-папки>` — создать папку с любым названием;
- `cd <название-папки>` — перейти в созданную папку.

2. В выбранной папке ввести `git clone` и вставить скопированную ранее ссылку. Например: `git clone git@github.com:techchronicler/git-guide.git`. Начнётся клонирование репозитория в папку на компьютере.

![](../screenshots/20260909172809.png) 
4. По завершении клонирования ввести в том же терминале команду `git pull`, чтобы загрузить все файлы с репозитория в локальную папку.
5. Открыть папку, в которую был склонирован репозиторий, и проверить успешную загрузку файлов.

![](../screenshots/20260909173828.png)

Теперь можно закрыть терминал и начать работу в созданной папке. Добавить туда необходимые файлы и картинки.

6. Когда работа завершена, нужно добавить изменённые файлы в репозиторий. Открыть терминал в папке, где производились изменения, и ввести команду `git add .`
7. Ввести комментарий о том, что было сделано, с помощью команды: `git commit -m "<место для комментария>"`.
8. Загрузить все изменения в репозиторий командой: `git push`.
9. Чтобы убедиться, что все изменения были успешно загружены, можно использовать команду: `git status`.
