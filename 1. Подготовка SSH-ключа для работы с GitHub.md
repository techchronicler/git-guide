Перед работой с репозиториями необходимо добавить SSH-ключ в учётную запись GitHub — это обеспечит безопасную аутентификацию без постоянного ввода пароля. Настройка выполняется один раз для каждого компьютера: на новом устройстве нужно сгенерировать и добавить отдельный ключ.

1. Открыть терминал сочетанием клавиш Ctrl + Alt + T.
2. Сгенерировать новый SSH-ключ выполнив команду:

```bash
ssh-keygen -t ed25519 -C "<ваша_почта>"
```

Вместо `<ваша_почта>` указать адрес электронной почты, привязанный к профилю GitHub, затем нажать «Enter».

![](../screenshots/20260909202757.png)

3. Далее система предлагает выбрать путь, по которому нужно сохранить файлы с ключами:
    - чтобы использовать путь по умолчанию, нажать «Enter»;
    - чтобы задать другой путь, нужно ввести его вручную, например: `/home/<имя_пользователя_пк>/.ssh/id_ed25519`

![](../screenshots/20260909203041.png)

4. Система запросит passphrase — это дополнительная защита приватного ключа. Даже если злоумышленник получит доступ к файлу ключа, без passphrase он не сможет его использовать.
    - для максимальной безопасности рекомендуется задать надёжный пароль;
    - если работа ведётся на личном устройстве и нужно избежать постоянного ввода passphrase, можно оставить поле пустым — для этого нажать «Enter» без ввода текста.

![](../screenshots/20260909203153.png)

После ввода пароля система попросит повторно ввести passphrase для подтверждения.

5. После завершения настройки passphrase появится сообщение об успешном сохранении ключей:

```bash
Your identification has been saved in ...
Your public key has been saved in ...
```

Здесь:
    - **identification** — _приватный ключ_ (файл без расширения). Его нельзя передавать другим и загружать на GitHub;
    - **public key** — _публичный ключ_ (файл с расширением `.pub`), который нужно добавить в GitHub.

Также система отобразит:
 - отпечаток ключа (fingerprint) в формате SHA256 

```bash
The key fingerprint is:
SHA256: ...
```

 - randomart‑изображение (ASCII‑арт):

```bash
The key's randomart image is:
+--![](../ED25519 256]--+
...
+----![](../SHA256]----+
```

Fingerprint — это короткий уникальный идентификатор публичного ключа. Его можно использовать для проверки подлинности при подключении к серверу.

6. Чтобы не вводить passphrase при каждом обращении к репозиторию, нужно подключить приватный ключ к SSH-агенту. Для этого вставить в терминал команды ниже:

```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

Команда запускает SSH-агента в текущей сессии терминала и настраивает переменные окружения, а затем добавляет приватный ключ в агента.

![](../screenshots/20260915135154.png)

Об успешном запуске агента говорят следующие результаты:
- `Agent pid <ID>` 
- `Enter passphrase for ...` — если passphrase была задана на этапе генерации ключа, система попросит ввести её один раз. После этого агент «запомнит» ключ на время сессии;
- `Identity added: ...` — ключ успешно добавлен в агент.

 7. Чтобы добавить ключ в GitHub, нужно скопировать содержимое публичного ключа (файл с расширением ".pub"). Для этого открыть файл через командную строку командой `cat ~/.ssh/id_ed25519.pub` и нажать «Enter». Результат команды скопировать в буфер обмена.

![](../screenshots/20260909165002.png)

8. Зайти в свой профиль GitHub и перейти в настройки.

![](../screenshots/20260909165700.png)

9. В разделе настроек выбрать «SSH and GPG keys» → «New SSH key».

![](../screenshots/20260909165842.png)

10. Заполнить поля. Ввести название ключа, например «Работа». Выбрать тип ключа «Authentication Key» — это стандартный тип ключа для проверки подлинности пользователя при подключении по SSH. В поле «Key» ввести скопированный ранее ключ. Нажать «Add SSH key».

![](../screenshots/20260909170008.png)

11. Далее подтвердить аккаунт. На почту профиля придёт код подтверждения — его нужно ввести в поле «Password». Нажать «Confirm».

![](../screenshots/20260909171421.png)

12. Сохранённый ключ будет отображаться в настройках в разделе «SSH and GPG keys».

![](../screenshots/20260915185014.png)

13. Далее можно проверить настроенную связь через терминал с помощью команды:

```bash
ssh -i ~/.ssh/id_ed25519.pub
```

В ответе должно быть " Hi < name>!..".

![](../screenshots/20260909171859.png)
